# 品質要求（抜粋）

## 負荷からの保護

利用者一人あたりの操作の回数に上限を置く。フォローとフォロー解除は合わせて20回/分、100回/日まで。ホームタイムラインの取得は60回/分まで。上限を超えた要求は、時間を置いてもらう応答を返す。

## 外部サービスの契約

利用者の登録では、認証サービスの利用者の照会 API を呼んで、メールアドレスが確かめられているかを見る。照会 API は従量課金で、契約上の上限は1日あたり10,000回である。上限を超えると、その日の残りは照会できず、登録が全員止まる。

## 運用

タイムラインの作り直しは、障害の後に運用者が手で起動する。全利用者のホームタイムラインを作り直すので、一回で数十分かかる。
